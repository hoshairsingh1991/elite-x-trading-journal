====================================================
ELITE X — MASTER UI COLOR STANDARD
====================================================

PRIMARY CARD / SURFACE
bg-[#0b1220]

SECONDARY / HOVER / DARK CONTROL
bg-[#0b0c1e]

DRAWER / SIDEBAR SHELL
bg-[#07111d]
bg-[#07111C]

STANDARD BORDER
border-white/[0.06]

STANDARD HOVER BORDER
border-white/[0.12]

STANDARD CARD RADIUS
rounded-[8px]

RULE
Use #0b1220 for normal application surfaces/cards.

Use #0b0c1e for darker controls, nested surfaces,
and hover states.

Use #07111d / #07111C for major shell surfaces such
as drawers and sidebar.

Use white/[0.06] for the standard subtle border.

Use white/[0.12] for hover borders.

Keep semantic colors unchanged:
green = positive/success
red = negative/danger
blue = primary/action/selected
amber/yellow = warning
cyan/violet/orange/etc. = semantic category indicators

Do not replace semantic colors with the neutral
surface palette.

8px is the default Elite X UI radius.
